# Repositorios de Microsoft asociados con Intune

Índice de la búsqueda pública [microsoft / Intune](https://github.com/orgs/microsoft/repositories?q=intune), consultada el 2026-11-05. **Un repositorio publicado por Microsoft no implica que su código sea una característica vigente o soportada de Intune.** Los marcados como archivados se tratan como históricos.

## Principales activos
- [shell-intune-samples](https://github.com/microsoft/shell-intune-samples): scripts de shell, principalmente macOS/Linux.
- [mggraph-intune-samples](https://github.com/microsoft/mggraph-intune-samples): automatización mediante Microsoft Graph PowerShell.
- [Intune-PowerShell-SDK](https://github.com/microsoft/Intune-PowerShell-SDK): SDK PowerShell, verificar compatibilidad actual.
- [Microsoft-Win32-Content-Prep-Tool](https://github.com/microsoft/Microsoft-Win32-Content-Prep-Tool): empaquetado Win32.
- [Intune-Resource-Access](https://github.com/microsoft/Intune-Resource-Access): ejemplos de acceso a recursos.
- [Intune-Data-Warehouse](https://github.com/microsoft/Intune-Data-Warehouse): integración/reportes.
- [Intune.Graph](https://github.com/microsoft/Intune.Graph): ejemplos Graph.
- [Zero-Trust-Lab-Securing-Identities-and-Devices-with-Intune-and-Entra](https://github.com/microsoft/Zero-Trust-Lab-Securing-Identities-and-Devices-with-Intune-and-Entra): laboratorio Zero Trust.
