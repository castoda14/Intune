Copias para **consulta y estudio**, no despliegue automático. Mantener rutas, autoría, licencias originales y referencia a la versión de origen.

- `microsoft/shell-intune-samples`: selección de instaladores vigentes de Company Portal en macOS, licencia MIT; fuente: https://github.com/microsoft/shell-intune-samples/tree/master/macOS/Apps/Company%20Portal
- `n-engelhardt/bitlocker-scripts`: scripts de BitLocker y licencia AGPL-3.0, fuente: https://github.com/n-engelhardt/bitlocker-scripts
- `wompRS/Proactive-Remediation-Scripts`: colección de remediaciones con licencia MIT, fuente: https://github.com/wompRS/Proactive-Remediation-Scripts

**Nota:** algunas remediaciones heredadas pueden modificar configuraciones de seguridad o requerir rollback. Leer el código completo antes de adaptarlo.
